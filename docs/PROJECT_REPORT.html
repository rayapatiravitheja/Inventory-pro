1. Executive Summary & Abstract

InventoryPro is an enterprise-grade full-stack MERN application that merges industrial multi-facility warehouse operations with consumer digital commerce. Designed to eliminate the vulnerabilities of single-location tracking and concurrent overselling, the platform incorporates strict atomic database updates ($gte guards), Mongoose multi-document ACID transactions, production Razorpay live payment capture (UPI, Cards, NetBanking), 7-day customer return workflows (RMA) with automated gateway refunds, a 3-tier Port 443 HTTPS email failover pipeline (Brevo v3 and Resend), and immutable double-entry ledger bookkeeping.

2. System Architecture & RBAC

The application follows the modular Controller-Service-Repository design pattern. The React 18 frontend communicates through Axios interceptors passing signed JWT tokens via HTTP-only cookies and Authorization headers to an Express 4.x ESM backend on Render.

1. Frontend Layer: React 18, Vite 6, Tailwind CSS, Ant Design 5 (Vercel)
2. API Layer: Express 4.x ESM, verifyJWT, requireRole, Multer, PDFKit (Render)
3. Database Layer: MongoDB Atlas M0 Cluster (17 Schemas, Compound Indexes, ACID)
4. Cloud Services: Razorpay Live, Brevo HTTPS API, Cloudinary CDN
